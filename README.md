# Neon Tic Tac Toe

A two-player neon arcade tic-tac-toe game built with React, TypeScript, Vite, and GSAP.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Play

- X (cyan) goes first
- Click an empty cell to place your mark
- First to three in a row wins the round
- Scores persist across rounds until you reset them
